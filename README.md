## 🗺️ What is this repo?

This is my complete, day-by-day study log for landing a MAANG AI/ML engineering role. Every day has an exact task, the resource to open, and space for my notes and learnings.

The plan covers everything MAANG AI/ML interviews test in 2026:
- **DSA** — 95+ LeetCode problems (NeetCode 150 order), one per weekday
- **LLM Engineering** — fast.ai L1–8, HuggingFace NLP, Karpathy GPT, LangChain, LangGraph, MCP
- **ML Fundamentals** — StatQuest (bias-variance, L1/L2, KL divergence), time-series
- **Production ML** — MLflow, RAGAS, Evidently AI, LangSmith, FastAPI, LoRA/QLoRA
- **Projects** — 3 live GitHub projects with HuggingFace Spaces demos
- **System Design** — 20 written answers, ByteByteGo + Chip Huyen
- **Mock Interviews** — 8 Pramp sessions + STAR stories
